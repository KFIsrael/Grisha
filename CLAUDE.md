# Grisha — сайт-витрина бренда

Сайт московского бренда женской одежды **Grisha** и его бутика на ул. Плющиха, 20/2. Магазин работает с 2017 года (начинали как мультибренд русских дизайнеров), на Плющихе — последние три года, до этого был в другом месте. На Wildberries бренд назывался Grisha Official. Telegram-канал бутика называется «Апрель» (@april_moscow), Instagram — @aprilmoscow (имя профиля Grisha.official). Ссылки на них оставлены как есть. **На сайте везде пишем Grisha**, так решил клиент.

Сейчас сайт — **витрина без онлайн-оплаты**: заказ идёт через WhatsApp, сообщение с товаром и размером заполняется автоматически. **Ссылок на Wildberries на сайте нет**: клиент уходит с WB.

Решения по проекту и договорённости с клиентом лежат в `CLAUDE.local.md`. Этот файл не попадает в git, потому что репозиторий публичный.

## Стек

- Next.js 16 (App Router), React 19, TypeScript
- Оформление на обычном CSS, всё в `src/app/globals.css`. Tailwind не используется.
- Шрифты: Cormorant Garamond для заголовков, Inter Tight для текста (подключаются через `next/font`)
- Хостинг: Vercel

## Структура

- `src/data/products.ts` — каталог: товары, категории, описания. Чтобы добавить товар, допишите объект и положите фото в `public/images/p/{slug}-{n}.webp`.
- `src/data/site.ts` — контакты, ссылки, номер WhatsApp.
- `src/app/page.tsx` — главная: первый экран, манифест, категории, новинки, линия Grisha, образы, бутик.
- `src/app/catalog` — каталог с фильтрами (`?c=new|outerwear|knit|tops|trousers|denim|skirts`) и карточки товаров `/catalog/[slug]`.
- `src/app/about`, `src/app/contacts` — страницы «О нас» и «Бутик».

## Откуда материалы

- Фото, состав и размеры взяты из карточек Grisha Official на Wildberries: это собственные студийные съёмки бренда. Их Telegram ссылается на эти карточки, а профиль в Instagram называется Grisha.official.
- Пуховик и парка взяты из Telegram: это та же студийная съёмка, на WB их нет. Разрешение 600×800, нужны оригиналы.
- Футболки с принтами и свитшоты со стразами убраны, потому что не подходят к стилистике quiet luxury.
- **Чужие фото из Telegram и Instagram не используем.** Большая часть снимков там чужая (папарацци, блогеры, лукбуки других брендов). Брать можно только студийную съёмку самого бренда.

## Что нужно от клиента (открытые вопросы)

- Цены. В данных их пока нет; поле `price` выводится автоматически, когда его заполнят.
- Логотип. Сейчас вместо него набранный шрифтом вордмарк GRISHA.
- Оригиналы съёмок в высоком разрешении: сейчас 900×1200, для первого экрана мало. Нужны также фото бутика.
- Часы работы бутика, юридическая информация для подвала, политика конфиденциальности.
- Тексты на сайте — черновик, их нужно согласовать.
